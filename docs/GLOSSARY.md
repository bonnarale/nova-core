# Glossary

| Term | Definition |
|------|-----------|
| **Cognitive Engine** | Core reasoning and decision-making pipeline |
| **Knowledge Graph** | Entity-relationship graph for structured knowledge |
| **Learning Engine** | System for extracting and consolidating knowledge from interactions |
| **Memory System** | Short-term (conversation) and long-term (persistent) memory |
| **Reasoning Engine** | Multi-strategy reasoning chain with evaluation |
| **Goal Engine** | Goal decomposition, tracking, and analysis |
| **Task Engine** | Task lifecycle management with state transitions |
| **Planning Engine** | Task planning with strategies and replanning |
| **Execution Engine** | Step-by-step execution with context management |
| **Multi-Agent Runtime** | Agent registration, dispatch, and coordination |
| **Tool System** | External tool registration and execution |
| **Model Gateway** | LLM provider abstraction with caching and load balancing |
| **RAG** | Retrieval-Augmented Generation — document retrieval + LLM context |
| **Vector Memory** | ChromaDB-backed vector storage for similarity search |
| **Event System** | Pub/sub event bus with middleware and replay |
| **Scheduler** | Cron, interval, and trigger-based job scheduling |
| **Workflow Engine** | Visual workflow compilation and execution |
| **Plugin System** | Hot-loadable plugins with sandbox isolation |
| **Security** | Authentication, authorization, and audit |
| **Observability** | Metrics, tracing, logging, health checks, and alerts |
| **API Platform** | FastAPI REST endpoints with versioning |
| **Database Architecture** | SQLAlchemy async ORM with repositories |
| **Deployment** | Docker, Kubernetes, and health check management |
| **Scaling** | Load balancing, worker pools, and autoscaling |
| **Feature Flags** | Runtime feature toggle system |
| **Experiments** | A/B testing and canary release infrastructure |
| **Capabilities** | Registry of future feature capabilities |
| **Deprecation** | Tracking deprecated features and migration paths |
| **ABC** | Abstract Base Class — interface contract for providers |
| **Strategy Pattern** | Pluggable algorithm behind provider interfaces |
| **Clean Architecture** | Domain logic isolated from infrastructure |
